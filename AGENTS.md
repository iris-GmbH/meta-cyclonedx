## Agent skills

### Issue tracker

Issues are tracked as GitHub issues on the maintained fork via the `gh` CLI, with epics as parents and tickets as sub-issues. Archived pre-migration tickets remain under `.scratch/<feature-slug>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage roles use the five canonical local status strings. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with `CONTEXT.md` and `docs/adr/` at the root. See `docs/agents/domain.md`.
